# ADR 0026：可读的共享 TOML 配置与旧配置自动迁移

- 状态：提议
- 日期：2026-11-25
- 基于：[ADR 0017](0017-config-env-as-a-command.md)、[ADR 0012](0012-cloud-backed-agentic-backend.md)
- 英文：[English](0026-shared-toml-config.md)
- 范围：CLI／host 共享配置、安装命令、存量用户升级。

## 背景

现有 `~/.memu/config.env` 直接采用进程环境变量名称。全大写、平铺的 `MEMU_*`
重复了应用命名空间，也使 Cloud 密钥、embedding 密钥、检索和 host 配置之间的关系
不易阅读。`init` 只展示部分配置；其余选项需要用户从源码或文档中发现并自行新增。
继续往这种格式添加开关，会延续同样的可用性问题。

存量用户已有密钥、数据库位置、embedding 模型、检索阈值、代理设置和稳定客户端 ID。
升级应继承这些值，不要求重新填写，也不能改变数据库或 embedding 空间；多个 host
同时启动时也应安全完成迁移。

## 决策

使用 `~/.memu/config.toml`，采用小写分组键。内部保留共享环境变量名称接口，CLI
参数、host adapter 和后端构造仍使用同一个解析入口。`config_schema.py` 定义映射；
`config_template.toml` 提供可直接修改的常用项和带注释的高级示例。迁移不推断数据库
位置或 embedding 模型。

例如：`cloud.api_key`、`embedding.api_key`、`retrieval.cloud.min_score.short`、
`network.proxy`、`telemetry.enabled`、`hosts.cowork.roots`、`sources.docs`。
分数和批量大小使用数字，开关使用布尔值，Cowork 目录使用数组。可选空字符串保持原有
“未设置／关闭”的语义。文档源、诊断和 Cowork 等高级选项同时支持共享文件和环境变量。

### 升级与优先级

1. 首次访问配置文件时，如果存在旧 dotenv 而 TOML 尚不存在，则自动迁移。安装 Python
   包本身不运行迁移，因此 `config show` 可能先执行一次迁移，再展示配置。
2. 使用现有 Windows BOM／编码兼容逻辑读取旧文件。转换已知键、合并旧 embedding
   提供商别名并验证类型。只读取磁盘值，不把当前 shell 的临时覆盖持久化。
3. 持有跨进程文件锁，再次检查目标是否存在；写入同目录临时文件后原子替换发布。
   原 dotenv 字节完全保留，作为回退副本；只有获得锁的进程发布迁移结果。
4. 已有 TOML 是唯一生效的文件，不逐项回退旧文件。自动迁移失败时，仅以异常类型告警，
   继续读取原配置。已有 TOML 不合法则报错，避免静默切换到旧密钥或另一个数据库。
5. 显式环境变量继续优先于文件，支持以空字符串关闭功能的选项仍保留该语义。旧提供商
   环境变量别名也优先于迁移后的文件取值。

`MEMU_CONFIG` 显式指定 TOML 目标路径。现有 `MEMU_CONFIG_ENV` 继续指定迁移源；
未显式指定目标时，在源文件旁生成 `.toml` 文件。源文件若本来就以 `.toml` 结尾，
则使用 `.migrated.toml`，防止覆盖原文。默认目标是 `~/.memu/config.toml`。

### 数据保留与写入

未知旧键以字符串保存在 `[legacy]`，提示只列键名。这样自定义或未来设置仍可通过
原解析接口读取。旧注释完整保存在保留的源文件中；后续 TOML 写入保留 TOML 注释、
顺序、未知分组及用户其他设置。

稳定客户端 ID 原值迁入相邻的 `.state.toml`，由程序管理，不作为用户配置选项。
现有命令和事件调用方继续使用同一内部键接口。子进程任务标记继续作为进程变量传递。

配置和状态文件使用带 `fsync` 的 UTF-8 原子写入。POSIX 新建目录权限保持 `0700`、
文件保持 `0600`。Windows 与现状一致，继承 ACL，不宣称额外的权限保护。

使用 `tomlkit` 保留 TOML 注释进行编辑，使用 `filelock` 跨进程加锁。迁移完成后的
命令更新也使用同一把锁。

## 影响与验证

- 存量用户保留已有配置，可以直接编辑新写法。
- 新用户在生成文件中看到常用项，并能发现高级项。
- 降级仍可读取保留的 dotenv，但 TOML 修改不会反向同步；降级前应核对当前取值。
- 此迁移不改变检索调度、模型调用、数据库结构或 embedding 行为。查询提炼策略 PR
  在此基础上适配。
- README 和公开 docs site 的配置说明另行协同整理。
- 验证迁移／幂等性、所有公开键映射、别名、类型校验、安全诊断、空值关闭语义、编码、
  写入失败回退、跨进程及多写入者并发，以及已有安装保护规则。
